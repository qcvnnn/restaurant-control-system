# Бронирование столиков в ресторанах

Учебное настольное приложение для поиска ресторанов, бронирования столиков и управления записями.

**Стек:** Python, PyQt5, SQLite, Pillow.

## Возможности

- Регистрация и вход с ролями пользователя и администратора.
- Поиск ресторанов по названию, описанию и адресу.
- Просмотр карточки ресторана, отзывов и оценок.
- Выбор даты и времени, отображение числа свободных столиков.
- Создание, просмотр и отмена своих бронирований.
- Просмотр списка бронирований, добавление и удаление ресторанов администратором.

## Запуск

```bash
git clone --branch master https://github.com/qcvnnn/restaurant-control-system.git
cd restaurant-control-system
python -m venv .venv
```

Активируйте окружение, затем установите зависимости и запустите приложение:

```bash
python -m pip install PyQt5 Pillow
python main.py
```

Запускайте из корня проекта: база `database.db`, формы и изображения используются по относительным путям. Совместимость версий PyQt5 и Pillow отдельно не зафиксирована.

## Структура

- [main.py](main.py) — запуск приложения.
- [db.py](db.py) — запросы к SQLite.
- [windows/windows.py](windows/windows.py) — логика окон и пользовательских действий.
- [ui](ui) — формы интерфейса.
- [images](images) — изображения ресторанов.

## Границы проекта

Локальный учебный прототип. Подтверждение бронирования реальным рестораном, уведомления и серверная синхронизация не реализованы. Проверка доступности и защита от одновременного бронирования требуют доработки для многопользовательской эксплуатации.
